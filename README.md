# Cross-Section Digitizer QGIS Plugin

[![License: BSD-3-Clause](https://img.shields.io/badge/License-BSD_3--Clause-blue.svg)](LICENSE)

A QGIS plugin for georeferencing and digitizing geological cross-sections (1D and 2D subsurface data). Part of the CRESCENT Community Fault Model tooling.

**Related tutorial:** https://cascadiaquakes.github.io/fault-geometry-building-tutorial/

---

## Installation and Use

Requires QGIS 3.0 or later. Installation and use instructions are forthcoming.
