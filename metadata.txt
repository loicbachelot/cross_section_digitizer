about=CrossSectionDigitizer extracts spatial data from geological cross-sections, depth-migrated seismic sections, and other vertical images. Define image-to-section control points, tie the section to geographic locations, and digitize faults, horizons, or other features. Export digitized series as CSV or georeferenced 3D point layers, create a 3D polygon representing the image extent, and save project settings and digitized data as JSON.
    Developed as part of CRESCENT's tools for constructing complex 3D fault geometries. A modified Qgis2threejs plugin supports visualization of the georeferenced images, while Contours2Mesh supports subsequent fault-surface construction. These companion plugins are optional and are not required for digitizing or georeferencing. No additional Python packages beyond the QGIS Python environment are required.
